# 商标申请候选图检查表

`trademark-candidates/` 中的文件是从当前网站矢量稿生成的候选图，不代表已经确定申报策略。

提交前逐项确认：

- [ ] 已用原设计方 AI/EPS/PDF 或签字版规范图核对全部轮廓。
- [ ] 已决定分别申请“中文文字”“英文文字”“独立图形”和“组合标志”中的哪些版本。
- [ ] 已决定是否主张颜色；不限定颜色时使用黑白候选图。
- [ ] 不把实体标志的厚度、阴影、材质纹理和安装结构加入申请图样。
- [ ] 小标语是否进入组合商标已由代理人给出明确意见。
- [ ] 申请主体名称与营业执照完全一致。
- [ ] 已完成相同/近似查询，并确定商品和服务类别及具体项目。
- [ ] 最终 JPG 清晰、无透明背景，尺寸及文件大小符合当前申请系统页面提示。
- [ ] 尚未核准注册前，不在实体标志上使用 `®`。

建议优先评估：独立图形黑白稿、独立图形彩色稿、不带小标语的横向组合稿。中文和英文文字是否单独申请，应由商标代理人结合检索结果确认。
